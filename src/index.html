KONEKSI LOKAL

Satu tempat untuk melihat traffic.

Pilih cara menghubungkan browser ke Arus.

01

Browser Arus Direkomendasikan

Masukkan URL dan klik Buka browser. HTTPS sudah siap. Sertifikat hanya dipercaya di browser ini, tanpa mengubah sistem.

02

Browser lain melalui proxy

Atur proxy HTTP dan HTTPS browser ke alamat berikut. Port dapat berubah saat Arus dibuka ulang.

Menyiapkan mesin…

Untuk HTTPS, export CA Arus lalu import ke Trusted Root Certification Authorities pada akun Windows kamu. Kembalikan pengaturan proxy dan hapus CA saat selesai.

Hanya traffic yang melewati proxy Arus yang tertangkap. Aplikasi dengan certificate pinning mungkin menolak koneksi. WebSocket frames dan streaming belum ditampilkan di versi ini.
EXPORT SESI

Simpan traffic sebagai HAR.

Export standar menghapus header login, menyamarkan parameter sensitif, dan menghilangkan body. URL dan header lain tetap perlu diperiksa sebelum dibagikan.
REQUEST COMPOSER

Edit. Periksa. Kirim ulang.

Request dikirim tanpa cookie browser otomatis. Header yang kamu isi tetap dikirim. Redirect tidak diikuti.
